# Usage Guide

This document describes how to use this simple project.

## Run the Program

Enter the `src` directory and run:

```bash
python main.py
```

The program will print arithmetic results and display a simple task list.

## Run Tests

From the root directory of the repository, run:

```bash
python -m unittest discover tests
```

## Git Experiment Usage

This project is mainly used to practice the following Git operations:

1. Clone a remote repository.
    
2. View all branches.
    
3. Create a new branch based on an existing branch.
    
4. Modify files on different branches.
    
5. Merge branches.
    
6. Resolve conflicts.
    
7. Push local branches to GitHub.
